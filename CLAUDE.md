# Tilework (theme development)

How to use the theme: `skill/SKILL.md`. Keep it in step with any API change.

- `theme/lib.typ`: entry point; `report` and `talk` deck types, slide layouts
- `theme/components.typ`: diagrams, charts, code, status
- `theme/ornament.typ`: tiles, edge border, stamp
- `theme/palette.typ`: the only place colors are defined
- `theme/tiles/`: generated by `python theme/make_tiles.py`; do not edit by hand
- `template/`: what `typst init` copies; also the test decks
- `design/`: the original design plan; the theme has since dropped the postmark and week number

After a change, install into a scratch location and render both test decks:

    export TYPST_PACKAGE_PATH="$PWD/build/packages" CLAUDE_CONFIG_DIR="$PWD/build/claude"
    sh install.sh
    for d in report talk; do
      typst compile --font-path theme/fonts --ppi 110 template/$d.typ "build/$d-{0p}.png"
    done

Look at every page. Before a breaking change, raise the version in `typst.toml` and in the
imports in `template/` and `README.md`, so existing decks keep their installed version.
